PreferMediaQueryPartialMethods

PreferMediaQueryPartialMethods class

Reports MediaQuery.of(context).property accesses that have a dedicated static accessor (e.g. MediaQuery.sizeOf(context)).

The specific accessors subscribe only to the relevant slice of MediaQueryData, preventing unnecessary widget rebuilds when other fields change.
